# 兆 kizashi — 易経スマホサイト

ひとつの問いを立て、卦を立てて、いまを静かに見立てる、易経のスマートフォン向け占いサイト。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 開発用ソース。`vendor/` と `hexdata.js` を `<script src>` で参照。 |
| `hexdata.js` | 64卦のコンテンツ（卦辞・意味・象・助言）と `LINES_FOR` 逆引き表。 |
| `vendor/` | React 18 / ReactDOM / html-to-image（CDN 非依存にするためローカル同梱）。 |
| `build.js` | 上記をすべてインライン化し、単一の `dist/index.html` を生成。 |
| `dist/index.html` | **公開用の単一・自己完結HTML**（これ1枚をホストすれば動く）。 |
| `兆 kizashi.dc.html`, `support.js` | 元のデザインツール用プロトタイプ（参照用に保持）。 |

## ビルド

```sh
node build.js   # → dist/index.html を再生成
```

`index.html` / `hexdata.js` を編集したら再実行してください。

## 公開（デプロイ）

`dist/index.html` を任意の静的ホスティング（Netlify / Vercel / GitHub Pages / S3 など）に置くだけ。
唯一の外部依存は Google Fonts のみ（オフライン時は明朝/ゴシックの代替フォントへ自動フォールバック）。

## 主な機能

- 問いを立てる → 三つの石を六度投げて卦を立てる → 見立て（前回／今回／次の卦をスワイプ）
- 64卦の卦辞・意味にもとづく解説、変爻からの之卦（次に進む卦）
- 占い履歴（ジャーナル）／64卦の辞典・検索／結果のシェア・画像保存／はじめに・免責
- フルスクリーン・レスポンシブ、セーフエリア対応、カルーセルのキーボード/ARIA対応、`prefers-reduced-motion` 対応

## まだ静的な部分（将来の拡張）

「AI による読み解き」は現在ローカル合成のスタブ（`aiStub`）です。実バックエンドを足すときは
`aiStub(ctx)` の本体を `fetch(CONFIG.AI_ENDPOINT, …)` に差し替えるだけで接続できます。

> 占い結果・解説は娯楽および内省のための情報提供です。重要な判断は専門家にご相談ください。
> 入力した問いや履歴は端末（ブラウザ）内のみに保存され、外部へ送信されません。
