# 兆 kizashi — 水面投石演出 設計書（2026-07-05）

## 背景と目的

現状の「兆 kizashi」は公開済みだが利用者がほぼいない。課題は2層ある: (1) 流通（人が来ていない）、(2) 来た人が触りたくなるフックの弱さ。本設計は「シェアされる体験づくり」を最優先目標とし、水面（参考: https://minamo-studio.netlify.app/ ）をアプリ全体の地として導入、投石演出をリッチ化する。演出リッチ化は製品改善であると同時に、note記事・XポストへのGIF/動画素材の製造でもある（流通課題への間接的な寄与）。

## 決定事項（ブレスト結果）

- 優先目標: シェアされる体験づくり（触って楽しい＋GIF映え）
- 水面の範囲: アプリ全体の地（全画面の最背面、どの画面でもタップで波紋）
- 投石演出: 「石が水面に落ちる」— 三つの石が着水し、波紋が干渉し、爻が水面に光として立ち上がる
- 技術方式: 素のWebGL（ping-pong height field による波動シミュレーション）。ライブラリ依存なし、単一HTML配布を維持
- three.js 同梱は非推奨として却下（配布サイズ肥大）
- Canvas 2D 案は却下（見た目のインパクト不足）。ただし非対応環境向けの降格先は静的背景とする
- 効果音はスコープ外（将来拡張）
- アプリ内録画機能は作らない（YAGNI）。画面録画で5秒ループGIFが撮れる品質を目指す

## アーキテクチャ

2層構造:

- 水のレイヤー: 最背面に固定の全画面 canvas（WebGL）。React の再レンダリングと独立したモジュールとし、命令型APIのみ公開する。例: water.drop(x, y, strength), water.calm(), water.setIntensity(mode)
- 紙のレイヤー: 既存の React UI。パネル類は不透明ベージュから半透明の「和紙が水に浮かぶ」風に調整し、水面が透けて見えるようにする
- 色調: 既存パレット（和紙ベージュ #f4f2ec 系、藍 #2f3a6e アクセント）を基調とした淡い水面とする。具体的な色・透過率は実装時に実機で調整する

インタラクション:

- UI要素（ボタン・入力・リンク等）以外の場所をタップすると、その座標に波紋が立つ（document レベルの pointer リスナーでフィルタ）
- 石は現行どおり DOM 要素（React）として落下アニメーションし、着水座標を water.drop() に渡す分業

シミュレーション実装:

- 高さマップを2枚のテクスチャで交互に更新する古典的 ping-pong height field 方式
- 描画シェーダで高さから法線を計算し、背景グラデーションの屈折＋スペキュラハイライトで水の質感を表現
- シェーダ・JS 合計 250〜350 行想定、外部依存ゼロ

フォールバック:

- WebGL 非対応、または prefers-reduced-motion 有効時: 水面 canvas を出さず、現状に近い静的背景へ自動降格。占い機能は一切影響を受けない

配布:

- 単一HTML配布（node build.js → dist/index.html）を維持。シェーダは文字列としてインライン
- 注意: build.js の String.replace は $& 等の特殊シーケンスを解釈する既知の落とし穴があるため、シェーダ文字列に $ を含む場合は関数置換を使うこと

## 投石演出の絵コンテ（シェアGIFの主役になる5秒間）

1. 静: 水面がかすかに揺らぎ、三つの石が待っている
2. 投: タップで石が持ち上がり、放物線を描いて落ちる（DOM transform）
3. 着水: 三つの着水点それぞれに波紋が立ち、波同士が干渉しながら広がる。石は一瞬沈んで浮かび上がり、表裏を見せる
4. 爻が立つ: 表裏の組み合わせから、水面に光の線（陽爻=一本線、陰爻=二本線）がゆらめきながら現れ、画面下の卦の積み上げへ収まる
5. 成卦: 六度目が収まると水面が一度大きく静まり、「結果を見る」ボタンが浮かぶ

画面ごとの水面の振る舞い:

- 問い入力・辞典・履歴など: 静かなゆらぎ＋タップで波紋のみ
- 投石画面: 上記の演出の主役
- 結果画面: 波をほぼ止め、読む邪魔をしない

## 性能・アクセシビリティ

- シミュレーション解像度は表示解像度と切り離し、上限 512 グリッド程度。DPR 上限 1.5
- document.hidden でループ完全停止。無操作が続いたらゆらぎだけの省電力モードへ
- prefers-reduced-motion: 水面アニメーションなし（静的背景）。既存のコイン演出の reduced-motion 対応は維持
- 半透明パネル上のテキストはコントラスト比を維持（読みやすさ優先）

## スコープ外（将来拡張）

- 効果音（着水音・環境音）
- アプリ内録画・GIF生成機能
- 流通施策そのもの（note記事公開、X運用）は本設計の範囲外だが、完成した演出が素材になる

## テスト・検証方針

- 機能リグレッション: 既存の投石→成卦→結果→シェアのフローが WebGL 有効/無効の両方で動くこと
- フォールバック検証: WebGL を無効化した環境、prefers-reduced-motion 有効環境での表示確認
- 実機検証: スマホ（iOS Safari / Android Chrome）での fps・発熱・バッテリーの体感確認
- build 検証: node build.js 後の dist/index.html が単体で動作すること（シェーダのインライン化が壊れていないこと）
